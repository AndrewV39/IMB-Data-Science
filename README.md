## 📘 Overview  
This repository showcases projects and notebooks completed during the **IBM Data Science Professional Certificate**, issued by **IBM** through **Coursera**.  
It covers the full data science lifecycle — from acquiring and cleaning data to exploring, modeling, and communicating insights using visualization and storytelling.

## 🚀 Capstone Project  
**Project Title:** *Analyzing and Predicting Neighborhood Demand for Venue Development*  

**Highlights:**  
- Collected and cleaned geospatial and venue data using APIs and Python.  
- Used clustering (K-Means) to identify promising business locations.  
- Developed predictive models to forecast growth potential.  
- Visualized insights in Power BI and presented actionable recommendations.
